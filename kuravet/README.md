# KuraVet (módulo Maven)

Este diretório contém o backend Spring Boot do KuraVet (`pom.xml`, `src/`).

A documentação completa (arquitetura, CI/CD, infraestrutura, banco, API, triagem por IA e testes) fica em um único lugar: **[README.md da raiz do repositório](../README.md)**.

Atalho para executar localmente a partir desta pasta: `.\mvnw.cmd clean spring-boot:run` (Windows) ou `./mvnw clean spring-boot:run` (Linux/macOS), depois de configurar as credenciais conforme [Como executar localmente](../README.md#como-executar-localmente).
